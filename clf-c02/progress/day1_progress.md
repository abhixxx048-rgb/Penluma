## Key Mistakes to Review
1. **CloudTrail vs Config** — Trail=WHO did what, Config=HOW resource changed over time
2. **SQS vs Step Functions** — SQS=queue messages, Step Functions=orchestrate workflow in order
3. **Lex vs SageMaker** — Lex=chatbot (pre-built), SageMaker=custom ML model (build from scratch)
4. Always use full AWS service names in exam (CloudFront not CDN, API Gateway not API)
