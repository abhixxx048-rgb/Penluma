# AWS Cloud Practitioner (CLF-C02) - Study Plan

## Exam Overview
- **Exam Code:** CLF-C02
- **Duration:** 90 minutes
- **Questions:** 65 (50 scored + 15 unscored)
- **Passing Score:** 700/1000
- **Format:** Multiple choice & multiple response
- **Cost:** $100 USD

## Exam Domains & Weightage

| Domain | Weight |
|--------|--------|
| 1. Cloud Concepts | 24% |
| 2. Security & Compliance | 30% |
| 3. Cloud Technology & Services | 34% |
| 4. Billing, Pricing & Support | 12% |

## Study Schedule

### Week 1: Cloud Concepts (Domain 1)
- [ ] AWS Cloud value proposition
- [ ] AWS Cloud economics (cost savings, right-sizing)
- [ ] Cloud architecture design principles (Well-Architected Framework)
- [ ] Migration strategies (6 R's)
- [ ] Cloud deployment models (Public, Private, Hybrid)

### Week 2: Security & Compliance (Domain 2)
- [ ] Shared Responsibility Model
- [ ] IAM (Users, Groups, Roles, Policies)
- [ ] Security services (WAF, Shield, GuardDuty, Inspector, Macie)
- [ ] Encryption (KMS, CloudHSM, at-rest vs in-transit)
- [ ] Compliance programs & AWS Artifact
- [ ] Network security (Security Groups, NACLs, VPC)

### Week 3: Cloud Technology & Services (Domain 3)
- [ ] Compute (EC2, Lambda, ECS, Fargate, Lightsail)
- [ ] Storage (S3, EBS, EFS, Glacier)
- [ ] Database (RDS, DynamoDB, Aurora, Redshift, ElastiCache)
- [ ] Networking (VPC, CloudFront, Route 53, Direct Connect, VPN)
- [ ] Management (CloudWatch, CloudTrail, Config, Systems Manager)
- [ ] AI/ML services overview
- [ ] Analytics services overview

### Week 4: Billing & Support + Practice Tests (Domain 4)
- [ ] Pricing models (On-Demand, Reserved, Spot, Savings Plans)
- [ ] Billing tools (Cost Explorer, Budgets, Calculator)
- [ ] Support plans (Basic, Developer, Business, Enterprise)
- [ ] AWS Organizations & Consolidated Billing
- [ ] Full-length practice tests
- [ ] Review weak areas
